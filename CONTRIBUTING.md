# Contributing

Thank you for helping improve Harbor for Scrypted.

## Before contributing

- Search existing issues and pull requests.
- Open an issue before proposing a large or incompatible change.
- Never include camera credentials, access tokens, private video, logs with
  secrets, personal data, or third-party proprietary code.
- Report suspected vulnerabilities privately as described in
  [SECURITY.md](SECURITY.md).
- Add or update tests and documentation with behavior changes.

## Review does not imply endorsement

Maintainers may review contributions for quality and security on a best-effort
basis. Review, approval, merging, or release does not certify, guarantee,
endorse, or warrant the contribution or project. Contributors and users remain
responsible for evaluating their code and deployments.
